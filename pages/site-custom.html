01 · Concept

01 · Concept

Créer une proposition sans copier le restaurant

Create a proposal without copying the restaurant

Site Custom fabrique des démonstrations clairement non officielles. Depuis Google Maps, l’automatisation ne réutilise que le nom de l’établissement : avis, notes, photos, horaires, adresse, téléphone, services et type de cuisine ne sont pas copiés automatiquement.

Site Custom creates clearly unofficial demos. From Google Maps, the automation only reuses the establishment name: reviews, ratings, photos, opening hours, address, phone number, services and cuisine type are not automatically copied.

Les contenus illustratifs restent identifiés comme fictifs, les démos sont en noindex, nofollow et les visuels réels doivent être fournis ou autorisés avant une mise en ligne officielle.

Illustrative content remains identified as fictional, demos use noindex, nofollow, and real visuals must be supplied or authorized before any official launch.

02 · Workflow

02 · Workflow

Un workflow GitHub Actions pour générer les démos

A GitHub Actions workflow to generate demos

Mode automatique

Automatic mode

Le workflow « Site Custom — URL » reçoit le lien du restaurant et tente les API configurées. Si elles ne répondent pas, une maquette illustrative peut tout de même être créée.

The “Site Custom — URL” workflow receives the restaurant link and tries configured APIs. If they are unavailable, it can still create an illustrative mockup.

Assistant externe

External assistant

Un mode en deux étapes prépare un texte à copier dans un assistant externe, puis importe sa réponse JSON après validation.

A two-step mode prepares text for an external assistant, then imports its validated JSON response.

Publication & suivi

Publishing & tracking

La démo est construite par scripts/build.py, publiée sur le Worker Cloudflare, puis une issue GitHub sert de fiche prospect.

The demo is built by scripts/build.py, published on the Cloudflare Worker, and a GitHub issue becomes the prospect record.

E-mail prêt à transférer

Email ready to forward

Après publication, le système envoie seulement à ma propre boîte Gmail un message déjà rédigé avec le lien de démo. Aucun e-mail n’est envoyé automatiquement au restaurant.

After publishing, the system sends only my own Gmail inbox a prepared message containing the demo link. No email is automatically sent to the restaurant.

04 · Architecture

04 · Architecture

Génération statique + Worker Cloudflare

Static generation + Cloudflare Worker

Python · HTML · CSS · JavaScript · GitHub Actions · Cloudflare Workers · D1

  • Un template principal de restaurant est assemblé avec des données JSON par le build Python.
  • A main restaurant template is assembled with JSON data by the Python build.
  • GitHub Actions reconstruit et publie automatiquement la vitrine, les tarifs et les démos existantes à chaque push sur main.
  • GitHub Actions rebuilds and publishes the showcase, pricing page and existing demos on every push to main.
  • Une base D1 multi-restaurants a été créée et déclarée dans wrangler.toml ; le schéma sépare comptes, restaurants, démos, plats, horaires et contrats.
  • A multi-restaurant D1 database has been created and declared in wrangler.toml; the schema separates accounts, restaurants, demos, dishes, schedules and contracts.
  • Le Worker réserve /api/* aux contrôles D1 et aux futures fonctions sécurisées.
  • The Worker reserves /api/* for D1 checks and future secured functions.

05 · État actuel

05 · Current status

Automatisation en place, parcours client encore contrôlé

Automation in place, customer journey still controlled

Les démos et leur publication sont opérationnelles via les workflows du dépôt. En revanche, aucun compte client, administration persistante ou paiement Stripe n’est ouvert pour le moment.

Demo generation and publishing are operational through repository workflows. However, no client account, persistent administration or Stripe payment flow is currently open.

Le dépôt prépare aussi un formulaire public avec Turnstile, une vérification d’e-mail et un workflow de traitement des demandes vérifiées. Ces éléments restent désactivés par défaut tant que les protections anti-abus, les migrations D1 et les obligations de confidentialité ne sont pas validées.

The repository also prepares a public form with Turnstile, email verification and a workflow for verified requests. These remain disabled by default until anti-abuse protections, D1 migrations and privacy requirements are validated.
