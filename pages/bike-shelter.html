Le problème, la réponse

The problem, the answer

Projet Université de Lorraine · ENSEM · avec Cincinnati & Chongqing

University of Lorraine · ENSEM project · with Cincinnati & Chongqing

Le projet « Bike Shelter! » a été lancé par l’Université de Lorraine pour remédier au manque d’abris pour vélos sur ses différents campus. L’ENSEM a été sollicité pour créer un abri innovant, connecté, modulable et sécurisé. Ce projet a impliqué des étudiants de l’Université de Cincinnati (États-Unis) et de Chongqing (Chine), malgré les défis de la distance et de la langue.

The “Bike Shelter!” project was launched by the University of Lorraine to address the lack of bike shelters on its campuses. ENSEM was asked to create an innovative, connected, modular and secure shelter. The project involved students from the University of Cincinnati (USA) and Chongqing (China), despite distance and language challenges.

Site web & API

Website & API

Développement d’un site web en HTML / CSS / JS avec une API PHP pour obtenir le nombre de places disponibles, mis à jour depuis un Raspberry sur le serveur — carte interactive JavaScript (Leaflet) et API de vérification du CSN carte étudiante.

Website in HTML / CSS / JS with a PHP API for available spots, updated from a Raspberry Pi on the server — interactive JavaScript map (Leaflet) and student-card CSN verification API.

Design and prototyping of the 16 shelter locks with 4 Arduinos and 4 RFID readers. Arduinos connect wirelessly via XBee to the Raspberry Pi.

05 · Usage

05 · Usage

Utilisation typique

Typical use

  1. L’utilisateur se localise sur la carte. The user locates themselves on the map.
  2. Il trouve l’abri vélos le plus proche et vérifie qu’il reste de la place. They find the nearest shelter and check how many spots are free.
  3. Il clique sur le lien qui ouvre la position de l’abri dans Google Maps. They tap the link to open the shelter in Google Maps.
  4. Il trouve l’abri et sécurise son vélo. They reach the shelter and secure their bike.

Verrouillage & déverrouillage

Lock & unlock

Verrouillage

Locking

  1. L’utilisateur verrouille son vélo. The user locks their bike.
  2. Il passe sa carte sur le lecteur pour valider le verrouillage. They tap their badge on the reader to confirm.

Déverrouillage

Unlocking

  1. L’utilisateur passe sa carte. The user taps their badge.
  2. Son vélo est déverrouillé. Their bike is unlocked.
