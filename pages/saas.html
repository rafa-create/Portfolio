01 · Produit

01 · Product

RelancePilot

RelancePilot est un projet de suivi commercial pour les indépendants. L’interface rassemble les devis, les coordonnées des prospects, les montants, les statuts et les échéances afin de faciliter les relances manuelles.

RelancePilot is a sales follow-up project for independent businesses. The interface brings together quotes, prospect details, amounts, statuses and due dates to make manual follow-ups easier.

03 · Technique et statut

03 · Tech and status

Un MVP en validation

An MVP under validation

HTML · CSS · JavaScript · Cloudflare Workers · D1 (prévu) · Stripe (prévu)

Le dépôt contient une interface publique, un point d’entrée Worker, des routes API, un schéma de base de données et des tests. L’inscription, les données en production et les paiements réels ne sont pas encore validés : il s’agit d’un MVP expérimental, et non d’un service commercial ouvert.

The repository contains a public interface, a Worker entry point, API routes, a database schema and tests. Registration, production data and real payments have not yet been validated: this is an experimental MVP, not a commercially launched service.
