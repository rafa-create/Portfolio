01 · Produit

01 · Product

RelancePilot

RelancePilot

Le projet aide à suivre les opportunités commerciales : chaque devis peut être retrouvé avec son client, son montant, son statut, ses notes et sa date de relance. Le tableau de bord met en avant les devis en cours, les échéances atteintes, les montants en attente et les devis gagnés.

The project helps track sales opportunities: each quote can be found with its customer, amount, status, notes and follow-up date. The dashboard highlights open quotes, due follow-ups, pending amounts and won quotes.

Les relances restent volontaires : l’outil prépare le suivi, mais l’utilisateur envoie ses messages manuellement avec sa messagerie habituelle.

Follow-ups remain intentional: the tool organizes the work, while the user sends messages manually through their usual email client.

03 · Architecture

03 · Architecture

Cloudflare, sans serveur dédié

Cloudflare, without a dedicated server

HTML · CSS · JavaScript · Cloudflare Workers · D1 (prévu) · Stripe (code présent) · GitHub Actions

HTML · CSS · JavaScript · Cloudflare Workers · D1 (planned) · Stripe (code present) · GitHub Actions

  • Un Worker Cloudflare sert l’interface statique et route /api/* vers le contrôleur serveur.
  • A Cloudflare Worker serves static assets and routes /api/* to the server controller.
  • Le schéma D1 prévoit les comptes, sessions, devis, tentatives d’authentification et événements Stripe.
  • The D1 schema covers users, sessions, quotes, authentication attempts and Stripe events.
  • GitHub Actions vérifie la syntaxe, les tests unitaires JavaScript et les migrations SQLite.
  • GitHub Actions checks syntax, JavaScript unit tests and SQLite migrations.
  • Le projet est volontairement conçu pour rester sur des offres techniques gratuites tant qu’elles suffisent.
  • The project is intentionally designed to stay on free technical tiers while they are sufficient.

04 · État actuel

04 · Current status

Vitrine visible, production à valider

Showcase live, production still to validate

La vitrine est accessible publiquement, mais le README indique que l’API, la base D1 et les abonnements ne sont pas encore validés en conditions réelles. Les inscriptions restent fermées par défaut.

The public showcase is live, but the README states that the API, D1 database and subscriptions are not yet validated under real production conditions. Sign-ups remain closed by default.

Avant des utilisateurs ou paiements réels, il reste notamment à finaliser la vérification d’e-mail, la récupération de mot de passe, la suppression complète du compte, les textes légaux, les essais de bout en bout et les contrôles de sécurité.

Before real users or payments, remaining work includes email verification, password recovery, full account deletion, legal texts, end-to-end testing and security checks.
