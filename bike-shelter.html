Pi coordinateur, Arduino en routeurs

Pi as coordinator, Arduinos as routers

Chaque module parle au Raspberry via XBee. Le Pi vérifie le CSN, associe carte ↔ serrure, pilote LED / buzzer, et publie les places libres sur le site.

Each module talks to the Raspberry over XBee. The Pi checks the CSN, maps card ↔ lock, drives LED / buzzer, and publishes free spots to the website.

  • Raspberry Pi
  • Arduino UNO ×4
  • XBee S2C
  • PN532 RFID
  • PHP API
