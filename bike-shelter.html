Pi coordinateur, Arduino en routeurs

Pi as coordinator, Arduinos as routers

Chaque module de places parle au Raspberry via XBee. Le Pi vérifie le CSN de la carte étudiante, associe carte ↔ serrure, pilote LED / buzzer, et publie le nombre de places libres sur le site. Batteries remontées périodiquement vers le web.

Each spot module talks to the Raspberry over XBee. The Pi checks the student card CSN, maps card ↔ lock, drives LED / buzzer feedback, and publishes free spots to the website. Battery status is pushed to the web on a schedule.

  • Raspberry Pi — coordination, BDD, HTTP
  • Arduino UNO ×4 — serrures / locks par module
  • XBee S2C — liaison sans fil
  • PN532 RFID — badge étudiant 13,56 MHz
  • Site + PHP API — carte, places libres
