# Rafael Orset — Portfolio

Live: https://rafa-create.github.io/Portfolio/

Site portfolio ingénieur (FR / EN). Push sur `main` → GitHub Pages.

## Structure

```
index.html          page d’accueil
pages/              pages projet, formation, intérêts
css/                styles
js/                 i18n + navigation
images/             médias par sujet
icons/              favicons
cv/                 CV FR / resume EN
docs/               documents complémentaires
```

Les anciennes URLs à la racine (`/alten.html`, etc.) pointent maintenant vers `/pages/…`.

## Activer Pages

Repo → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch `main` / `/ (root)` → Save.

## Local

Ouvrir `index.html` ou servir le dossier :

```bash
npx --yes serve .
```
